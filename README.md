# analysis-of-security-events
Учебный анализ 37 записей журнала событий информационной безопасности.
Анализ событий информационной безопасности

О проекте

Учебный проект выполнен в рамках итоговой аттестационной работы по программе «Кибербезопасность: администрирование и мониторинг средств защиты информации».

Цель работы — изучить записи журнала событий информационной безопасности, выявить подозрительную активность, оценить возможные риски и предложить меры по повышению защищённости.

Исходные данные

Для анализа использовался предоставленный учебный журнал, содержащий 37 записей из разных источников:

- Windows — события входа в систему и изменения учётных записей;
- WEB-NGINX — запросы к веб-серверу;
- SYS-MON — запуск процессов и выполнение команд;
- EDR-ALERT — оповещения системы защиты конечных устройств;
- PA-NGFW — сетевые соединения и события межсетевого экрана;
- SYS-AUTH / LINUX-AUTH — события аутентификации.

Задачи

- Изучить записи журнала.
- Выделить обычные, подозрительные и потенциально опасные события.
- Сопоставить связанные события по времени, устройствам и другим признакам.
- Оценить возможные последствия.
- Сформулировать рекомендации по повышению безопасности.

Результат

В ходе работы рассмотрены примеры штатной активности, подозрительных веб-запросов и цепочки событий, указывающей на возможное выполнение вредоносного кода и подозрительное сетевое соединение.

Отдельное внимание уделено тому, чтобы не делать выводов, которые нельзя подтвердить имеющимися данными.

Статус проекта

Учебная работа. Описание и результаты будут дополнены по мере развития практических навыков.
